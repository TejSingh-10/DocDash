# Healthcare Management Dashboard

A full-stack web app for managing hospital and clinic operations — patients, appointments, staff schedules, and medical records. The project uses a monorepo structure with a Node.js/Express backend and a React frontend, keeping both sides in the same repo while allowing independent development and deployment.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React 18, Vite, Tailwind CSS |
| Backend | Node.js, Express |
| Language | JavaScript (ES Modules) |
| Monorepo | npm workspaces |
